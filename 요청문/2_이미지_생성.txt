## A. 저장소에 접근할 수 있는 AI (Codex, 로컬 에이전트 등)

작업 폴더는 C:\Workspaces\english\hackers_video_project_v2 하나뿐이다. 다른 폴더는 열지도 쓰지도 마라.
시작 전에 prompts/P2_이미지_생성.md 를 읽어라.

DAY 01~30의 전체 이미지를 만들어라. 기존 파일은 건너뛰고 누락분부터 이어서 진행해라.

1. 대상 목록을 뽑는다
   node remotion\scripts\generate-images-agy.mjs --set DAY01_01-10_set1 --list-missing
   (또는 remotion/public/days/DAY01_*/image_prompts.md 의 "## 파일명" 항목을 그대로 읽는다)
2. 프롬프트를 **한 글자도 바꾸지 말고** 그대로 써서 이미지를 만든다
   - 비율·해상도 옵션은 아무거나 둬도 된다. 규격은 우리 임포터가 맞춘다
   - 보강 문구를 임의로 덧붙이지 마라
3. 결과 파일을 **목표 파일명 그대로** inbox\<네이름>\ 에 저장한다
   예: inbox\gptimage2\01_chore_word.png  (확장자는 jpg·webp 여도 된다)
4. 규격 정규화해서 후보 보관함에 넣는다. author는 nanobanana2 또는 gptimage2다
   node remotion\scripts\import-images.mjs --author <네이름>
5. 보고: 만든 장수, 실패한 파일명, 임포터가 낸 경고(단색 의심·과다 크롭·업스케일)

하지 마라: 파일을 직접 리사이즈·크롭하지 마라. 최종 폴더(remotion/public/days/*/images)에
직접 넣지 마라 — 선별은 3단계에서 사람이 한다. TTS·렌더를 시작하지 마라.
같은 자산을 3회 실패하면 멈추고 handover.md 에 기록해라.

Codex 인 경우: sandbox 는 read-only 로 두고 파일 저장을 시도하지 마라. 생성물의 절대
경로만 답하면 이쪽에서 복사한다 (이 PC 의 Codex 샌드박스는 셸을 띄우지 못한다).

## B. 웹 UI 로 만들 때 (Google Flow, nano banana 등 — 사람이 조작)

1. 남은 목록을 뽑는다
   node remotion\scripts\generate-images-agy.mjs --set DAY01_01-10_set1 --list-missing
2. 프롬프트를 그대로 붙여넣어 생성한다. 비율 설정은 신경 쓰지 않아도 된다
3. 내려받은 파일을 목표 파일명으로 바꿔 inbox\<도구이름>\ 에 넣는다
   ("01_chore_word (1).jpg" 처럼 꼬리표가 붙어도 임포터가 알아본다)
4. node remotion\scripts\import-images.mjs --author <도구이름>

## 공통 규칙

- 한 세트(20장)는 되도록 한 도구로 만든다. 세트 안에서 그림체가 갈리면 눈에 띈다
- 프롬프트에 비율·해상도·no logo·no watermark 같은 문구를 추가하지 마라.
  그 지시가 잘림·단색 밴드의 원인이었다
- 실패한 자산만 다시 만든다. 성공한 이미지를 덮어쓰지 마라
- 재생성 시에만 보강 문구를 붙인다:
  글자 혼입  → Absolutely no letters, numbers, logos, or watermarks anywhere.
  피사체 잘림 → Show the whole subject with clear margin on every side.
  단색 밴드   → Fill the entire frame with the scene, no borders, no empty color areas.
  얼굴 부담   → Simple friendly cartoon characters, no realistic faces.
