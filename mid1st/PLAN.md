# mid1st — 중1 교과 주제 기반 영어 예문 후보 제작 계획

## 1. 목표

기존 1,200단어의 확정된 뜻과 품사를 기준으로, PART·DAY 주제와 중학교 1학년 교과 개념을
함께 고려해 공통 예문 주제를 먼저 정한다. `codex`, `antigravity`, `claude` 세 작성자는 같은
단어·뜻·교과개념을 입력받아 예문만 각각 작성하며, 결과는 단어별로 비교·선택한다.

이 작업은 기존 파이프라인과 데이터를 수정하지 않고 `mid1st/` 안에서만 진행한다.

## 2. 읽기 전용 기준 자료

| 자료 | 역할 |
|---|---|
| `../hackers.csv` | DAY·번호·단어 철자의 원본 |
| `../content/candidates/final/**/words.json` | 사람이 선택한 품사·한국어 뜻·IPA·영영 정의의 기준본 |
| `../part_day_table.md` | PART·DAY 주제 |
| `C:/Workspaces/junbe_study/middle_1st/content_eng/` | 중1 교과 개념 참고 자료 |

확인된 규모:

- 단어: 1,200개, DAY 01~30 × 하루 40개, 중복 없음
- 세트: 120개, 세트당 10단어
- 교과 개념: 국어 35 + 수학 34 + 과학 45 + 사회 39 = 153개
- 기존 최종 콘텐츠: 120/120세트가 현재 형식 검증을 통과함

## 3. 격리 원칙

- 위 기준 자료는 읽기만 하고 수정하지 않는다.
- 새 주제 필드는 기존 strict `words.json`에 추가하지 않는다.
- 주제 매핑과 새 예문은 `mid1st/candidates/<author>/`의 sidecar 파일로 보관한다.
- 최종 선택 뒤에도 기존 파일을 덮어쓰지 않고 `mid1st/final/`에 별도 결과를 만든다.

## 5. 처리 단계

### 단계 A — 입력 고정

1. `hackers.csv`와 최종 `words.json` 120개를 `(DAY, no, word)`로 대조한다.
2. PART·DAY 주제를 결합한다.
3. 품사·한국어 뜻·IPA·영영 정의를 변경 불가 기준 필드로 복사한다.
4. 10단어 단위 입력 세트 120개를 만든다.

### 단계 B — 교과 개념 카탈로그

`content_eng/*/keywords.md`에서 과목·영역·단원·한영 개념명·경로를 추출하고, 각 개념
페이지에서 관련어와 중1 맥락을 결합한다. 과목별 문서 형식이 다르므로 제목만으로 분류하지
않고 인덱스와 개별 페이지를 함께 사용한다.

### 단계 C — 공통 교과개념 배정

각 단어에 주 개념 하나를 배정한다. 먼저 단어의 확정된 뜻과 품사에 직접 맞는 개념만
후보로 남긴다. 적합도가 비슷하면 현재까지 사용 횟수가 적은 개념을 우선 검토한다.

- 모든 개념을 억지로 한 번 이상 쓰게 하지 않는다.
- 개념별 사용 횟수는 강제 할당량이 아니라 선택 시 참고하는 soft balance다.
- `direct` 또는 `contextual` 연결만 교과개념 배정으로 인정한다.
- 자연스러운 교과 연결이 없으면 `day_fallback`, 그것도 어렵다면 `word_fallback`을 쓴다.
- 비유·은유·말장난으로 단어와 교과개념을 연결하지 않는다.
- 배정 뒤 미사용·저사용·과다사용 개념을 보고하고, 적합도가 같은 항목만 재검토한다.

### 단계 D — 대표 샘플 보정

품사·PART·교과·연결 유형이 다른 소수의 대표 단어에 대해 세 모델이 먼저 예문을 만든다.
사용자가 단어 뜻과 교과개념이 가장 선명한 예문을 고르면, 선택 결과를
`calibration/selected_examples.jsonl`에 기록한다. 본 생성에서는 이 문장들을 복제하지 않고
문장 선택 성향만 따른다.

### 단계 E — 세 모델의 독립 예문 후보 생성

세 작성자 모두 같은 공통 개념 배정표를 사용한다. 모델은 주제를 다시 고르거나 확정된
뜻·품사·IPA·영영 정의를 바꾸지 않고, 각 단어의 새 예문만 작성한다.

### 단계 F — 기계 검증

- 1,200개 완전성 및 `(DAY, no, word)` 일치
- 유효한 공통 교과 개념 ID 또는 허용된 fallback 값
- 지정된 뜻·품사 불변
- 예문에 표제어 철자 그대로 포함
- 예문 8~12단어
- 세트 안 반복 고유명사 방지
- 위험·폭력·상표·화면 글자 의존 표현에 대한 검토 표시
- 낮은 확신, 다의어, 단어·개념 직접성이 약한 문장을 사람 검토 대상으로 표시
- 개념별 사용량 요약과 미사용·저사용·과다사용 경고

형식 검증은 의미 정확성·자연스러움·교과 사실 정확성을 대신하지 않는다.

### 단계 G — 비교와 최종 생성

기존 예문과 `codex`·`antigravity`·`claude`의 새 예문을 단어별로 나란히 비교한다. 선택
manifest에는 단어별 선택 작성자와 필요 시 직접 수정안을 기록한다. 몇 개의 대표 선택으로
사용자 성향이 확인되면 AI가 같은 판단 기준으로 나머지 추천안을 만들되, 최종 선택 근거를
추적 가능하게 남긴다. 선택 결과를 `mid1st/final/`에 만들고 원본 데이터는 그대로 둔다.

## 6. 권장 매칭 우선순위

1. 확정된 한국어 뜻과 영영 정의
2. 확정된 품사와 대표 용법
3. 중1 교과 개념과의 직접적인 의미 관계
4. 자연스럽고 사실에 맞는 한 장면 예문을 만들 수 있는가
5. 위 조건이 같은 후보 중 현재까지 사용 횟수가 적은 교과개념
6. DAY 주제
7. PART 주제
8. 자연스러운 교과 연결이 없을 때 허용된 fallback

DAY·PART 제목보다 확정된 단어 뜻을 우선한다. 예를 들어 `press=누르다`, `plant=심다`,
`branch=나뭇가지`처럼 DAY 제목만 보고 다른 뜻으로 바꾸지 않는다.

## 7. 유지할 기존 예문 규칙

- 표제어 철자를 굴절시키지 않고 그대로 포함한다.
- 영어 8~12단어로 쓴다.
- 지정된 뜻과 품사의 자연스러운 대표 용법을 쓴다.
- 단어는 비유·은유가 아니라 확정된 뜻 그대로 직접 사용한다.
- 예문 하나만으로 독립된 한 장면이 보여야 한다.
- 추상어는 행동·표정·사물 상태처럼 보이는 장면으로 만든다.
- 예문끼리 이야기를 잇거나 고정 인물명을 반복하지 않는다.
- 상표·로고·유명 작품·유명 캐릭터와 화면 속 글자에 의존하지 않는다.
- 폭력·피·상처·무기·위협·공포·차별·선정성·모방 위험 행동을 피한다.
- 부정적 뜻은 의미를 유지하면서 판타지·동물·사물·게임 상황으로 안전하게 표현한다.
- 교과 개념을 사용할 때는 어려운 전문용어 삽입보다 정확한 사실이나 관찰 가능한 현상을
  쉬운 영어로 보여준다.
- 독자가 문장 안에서 목표 단어의 뜻과 교과개념의 핵심을 각각 직접 지목할 수 있어야 한다.
- `like`, `as if` 또는 의인화로 교과개념을 비유하는 문장은 후보에서 제외한다.
