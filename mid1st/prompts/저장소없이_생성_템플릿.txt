사용한다. 아래 입력의 단어 뜻, 품사, 영영 정의, PART·DAY, 교과 개념 배정은 이미 확정됐다.
이를 수정하거나 다른 개념으로 다시 배정하지 말고 sentence만 만들어라.

아래 예문은 사용자의 성향을 보여주는 참고 자료다.

{{SELECTED_EXAMPLES_JSONL}}

선택 예문의 구체성, 쉬운 문장 리듬, 단어 뜻과 교과 사실을 직접 드러내는 방식을 참고하라.
그러나 주어, 구조, 장소, 사물, 수식어, 구절을 복제하거나 표제어만 바꾼 패턴 문장을 만들지
마라. 선택 예문의 표면 형태가 아니라 판단 원칙만 일반화하라.

- 불변 배정: `conceptId`, `conceptKo`, `matchMode`, `rationaleKo`, `conceptCueKo`

## 예문 규칙

각 item마다 최종 영어 예문 하나만 만든다.

1. 영어 8~12단어다.
2. `word`의 표제어 철자를 그대로 포함한다.
3. 표제어를 복수형, 과거형, 3인칭 단수형, 비교급, 소유격 등으로 굴절시키지 않는다.
4. 표제어를 확정된 한국어 뜻·품사·영영 정의의 자연스러운 대표 용법으로 쓴다.
5. 초등 6학년이 읽을 쉬운 일반 어휘와 문장 구조를 쓴다.
6. `conceptCueKo`의 사실·관찰·측정·분류·계산·관계를 구체적으로 구현한다.
7. 단어 뜻과 교과 개념이 문장만 읽어도 둘 다 직접 확인되어야 한다.
8. “과학 시간에 배운다”처럼 과목 이름이나 전문용어만 배경에 붙이지 않는다.
9. 비유, 은유, 직유, 상징, 의인화, 말장난, figurative use를 쓰지 않는다.
10. 한 문장에 한 장면이나 한 과정만 담고, 사실에 맞으며 안전해야 한다.
11. 폭력, 피, 상처, 무기, 위협, 공포, 차별, 선정성, 위험한 실험을 피한다.
12. 상표, 유명 작품·캐릭터·인물, 화면 속 글자를 읽어야 하는 장면을 쓰지 않는다.
13. 열 문장의 주어, 장소, 사물, 문장 구조를 과도하게 반복하거나 이야기를 잇지 않는다.

`direct`와 `contextual`은 주어진 교과 개념을 그대로 쓴다. `day_fallback`이면 새 교과 개념을
끼워 넣지 말고 DAY 주제와 단어 뜻을 직접 보여준다. `word_fallback`이면 교과 연결을 억지로
만들지 말고 단어의 문자적 뜻이 가장 선명한 장면을 쓴다.

내부적으로 문장 후보를 2~3개 검토하되, 사고 과정과 탈락 문장은 출력하지 마라. 저장할 한
문장에 대해 exact word, 고정 뜻·품사, 8~12단어, concept cue, 비유 금지, 사실·안전 조건을
모두 다시 확인하라.

## 출력

설명이나 인사말 없이 아래 JSON 객체 하나만 JSON 코드블록으로 출력하라. 최상위 키와 item
키를 추가하거나 빼지 마라. 입력 순서를 유지한다.

```json
{
  "schemaVersion": 1,
  "author": "{{AUTHOR}}",
  "day": {{DAY_NUMBER}},
  "range": "{{RANGE}}",
  "set": {{SET_NUMBER}},
  "items": [
    {
      "wordId": "입력값 그대로",
      "no": 1,
      "word": "입력값 그대로",
      "sentence": "8~12단어의 최종 예문"
    }
  ]
}
```

후보 JSON에는 뜻, 개념, 선정 근거, 점수, 검토 메모를 넣지 마라. 오직 불변 identity와
sentence만 반환하라.
