# P0 — 대표 샘플로 예문 취향 보정

## 목적

1,200개 전량을 만들기 전에 같은 소규모 단어를 `codex`, `antigravity`, `claude`가 각각
작성한다. 사용자가 단어별로 가장 좋은 예문을 고르면, 그 선택에서 드러난 판단 원칙을
`selected_examples.jsonl`에 기록해 세 모델의 전량 생성에 동일하게 제공한다.

이 단계는 모델 순위를 정하거나 한 모델을 탈락시키는 시험이 아니다. 사용자가 좋아하는
구체성, 문장 리듬, 교과 연결 강도를 초기에 확인하는 보정 단계다.

## 선행 조건

P1의 공통 `mid1st/data/concept_assignments.jsonl`이 완성되고 검증을 통과해야 한다. 대표 샘플에서도
세 모델은 배정된 개념을 바꾸지 않고 예문만 만든다.

## 대표 단어 선정

이미 만들어진 `mid1st/calibration/representative_words.json`의 24개를 그대로 사용한다.
이 파일을 변경하거나 다시 뽑지 않는다. 대표 목록은 PART·품사·과목 장면·다의어 위험을
다양하게 시험하도록 배정 전에 준비되었으므로, 실제 P1 결과의 모든 matchMode가 들어 있다고
가정하지 않는다.

- 국어·수학·과학·사회의 서로 다른 장면 가능성
- 단어 뜻과 개념이 직접 또는 문맥 속 관계로 드러날 가능성
- 구체 명사, 추상 명사, 동사, 형용사·부사
- exact word 규칙 때문에 자연스러운 문장 설계가 필요한 표제어
- 다의어지만 뜻이 이미 고정된 단어
- 부정적 뜻을 안전하게 표현해야 하는 단어
- 사실 오류나 장식적인 교과 연결이 생기기 쉬운 단어

쉬운 단어만 뽑지 않는다. 한 과목, 한 DAY, 한 품사에 치우치지 않는다. 세 모델에 **완전히
같은 샘플과 같은 순서**를 준다.

공통 배정이 끝난 뒤 24개의 실제 `direct`, `contextual`, `day_fallback`, `word_fallback`
분포를 확인한다. 목록에 없는 matchMode가 있어도 대표 목록을 바꾸지 않는다. 그 유형은 본
생성 뒤 비교 보고서에서 별도 샘플링해 같은 선별 기준이 잘 적용되는지 확인한다.

## 모델별 생성

각 모델은 `P2_예문_후보.md`의 **예문 품질·자기 점검 규칙**을 그대로 적용한다. 다만 P2의
`selected_examples.jsonl` 선행 게이트, 1,200개 범위, 세트별 출력 형식은 P0에 적용하지 않는다.
P0는 그 사용자 선택 파일을 만들기 위한 선행 단계다. 출력 위치는 다음과 같다.

```text
mid1st/calibration/candidates/codex/sentences.jsonl
mid1st/calibration/candidates/antigravity/sentences.jsonl
mid1st/calibration/candidates/claude/sentences.jsonl
```

출력은 입력과 같은 순서의 JSONL 24줄이다. 빈 줄, 주석, 코드 펜스, 설명, 자체 평가를 넣지
않는다. 각 줄은 아래 네 키만 가진다.

```json
{"wordId":"입력값 그대로","no":1,"word":"입력값 그대로","sentence":"8~12단어의 최종 예문"}
```

세 모델의 파일 스키마에는 author를 넣지 않는다. 폴더명이 author를 나타낸다. 세 모델의
지시, 입력, 샘플 수, 품질 기준을 다르게 하지 않는다. 모델은 다른 모델의 후보를 보지 않은
상태에서 독립적으로 만든다.

각 author는 생성 직후 다음 형식 검증을 통과시킨다.

```powershell
node mid1st/scripts/validate-candidates.mjs --author codex --calibration `
  --report mid1st/calibration/candidates/codex/validation_report.md
```

`codex`를 자기 author로 바꾼다. 정확히 24개, 대표 목록과 identity 일치, strict 키, exact
word, 8~12단어가 모두 통과해야 한다.

## 사용자 비교 화면

비교할 때는 각 단어에 대해 다음만 함께 보여준다.

- `word`, 확정 한국어 뜻, 품사, 영영 정의
- PART·DAY 주제
- 공통 교과 개념 이름과 `conceptCueKo` 또는 fallback 장면
- 기존 baseline 예문, Codex 예문, Antigravity 예문, Claude 예문

선정 근거나 모델의 자체 평가는 비교 화면에 섞지 않는다. 사용자는 author 하나를 고르거나
직접 수정안을 승인할 수 있다. 판단 기준은 다음 순서다.

1. 확정된 단어 뜻과 품사가 가장 직접적으로 보인다.
2. 공통 교과 개념의 사실·관계가 가장 선명하다.
3. 비유나 은유가 아니며 두 요소가 한 장면에 자연스럽게 공존한다.
4. 초6이 읽기 쉽고 영어가 자연스럽다.
5. 안전하고 사실에 맞으며 시각화하기 쉽다.

## `selected_examples.jsonl`

사용자는 24개를 모두 고를 필요가 없다. 취향이 분명하게 갈리는 예문 중 대표적인 6~12개만
선택한다. 선택을 `mid1st/calibration/selected_examples.jsonl`에 대표 목록 순서대로 저장하며,
각 줄은 아래 네 키만 가진다.

```json
{"wordId":"입력 identity","selectedAuthor":"codex","sentence":"사용자가 선택하거나 승인한 문장","preferenceNoteKo":"단어 뜻이 행동으로 보이고 교과 관계도 직접적임"}
```

`selectedAuthor`는 `codex | antigravity | claude | baseline | manual` 중 하나다.
`preferenceNoteKo`는 모델 이름에 대한 평가가 아니라, 사용자가 그 문장을 고른 관찰 가능한
이유를 한 문장으로 적는다. 직접 수정안이면 `selectedAuthor`는 `manual`을 쓴다.

선택 문장은 P2의 형식·뜻·8~12단어·exact word 규칙을 통과한 것만 exemplar로 확정한다.

세 모델의 24개 파일이 모두 검증된 뒤 아래 명령으로 baseline을 포함한 비교표를 만든다.

```powershell
node mid1st/scripts/compare-candidates.mjs --calibration
```

기본 출력 `mid1st/calibration/comparison.md`에서 사용자가 6~12개를 고른다. 선택하지 않은
대표 단어는 `selected_examples.jsonl`에 넣지 않는다.

선택 파일을 저장한 뒤 다음을 통과시킨다.

```powershell
node mid1st/scripts/validate-calibration-selection.mjs --max 12 `
  --report mid1st/reports/calibration-selection-validation.md
```

strict 키, 대표 ID, 선택 author의 실제 문장, manual 문장, exact word, 8~12단어,
`preferenceNoteKo`를 모두 확인한다.

## 전량 프롬프트에 반영하는 법

세 모델은 전량 생성 전에 같은 `selected_examples.jsonl`을 모두 읽는다. 그 선택에서 다음과 같은
일반 원칙을 추출해 적용한다.

- 선호하는 장면의 구체성
- 쉬운 어휘와 문장 리듬
- 단어 뜻과 교과 사실을 드러내는 순서와 강도
- 허용되는 상상 요소와 안전한 표현 방식
- 사용자가 반복해서 거절한 모호함이나 장식적 연결

그러나 exemplar는 복사용 few-shot 문장 틀이 아니다.

- 주어·동사 구조·장소·사물·수식어·어구를 복제하지 않는다.
- 표제어만 교체한 문장을 만들지 않는다.
- exemplar의 캐릭터나 장면을 연속해서 재사용하지 않는다.
- 비슷한 개념이어도 새 단어와 `conceptCueKo`에 가장 직접적인 장면을 새로 설계한다.

## 단계 게이트

세 모델의 대표 샘플 중 사용자가 최소 6개를 선택하기 전에는 1,200개 전량 생성을 시작하지
않는다. 6~12개의 `selected_examples.jsonl`이 준비된 뒤에는 세 모델 모두 같은 파일을 입력으로
사용하며, 특정 모델만 추가 보정 예시를 받지 않는다.
