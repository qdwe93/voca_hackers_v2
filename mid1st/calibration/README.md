# 대표 샘플 보정

세 모델이 동일한 대표 단어·공통 교과개념으로 먼저 예문을 만든다. 사용자가 먼저 6~12개의
대표 예문을 선택해 `selected_examples.jsonl`에 기록하면 전 범위 생성 요청에 문체·판단 기준
예시로 넣는다. 24개를 전부 선택할 필요는 없다.

보정 예시는 복사할 문장 템플릿이 아니다. 다음 성향만 전달한다.

- 단어 뜻이 즉시 드러나는가
- 교과개념이 정확하고 직접적으로 보이는가
- 한 장면으로 그릴 수 있는가
- 쉬운 영어이면서 유치하거나 부자연스럽지 않은가
- 불필요한 비유·은유·전문용어가 없는가
