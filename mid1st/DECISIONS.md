# mid1st 확정 결정

확정일: 2026-08-22

## 기준 데이터

- 기존 1,200단어의 철자, 품사, 한국어 뜻, IPA, 영영 정의는 확정값으로 유지한다.
- 새로 생성하는 학습 필드는 예문뿐이다.
- 기존 예문은 비교용 기준선으로 보존한다.
- 기존 프로젝트 데이터는 수정하지 않고 모든 새 산출물을 `mid1st/`에 둔다.

## 교과개념 배정

- 국어 35, 수학 34, 과학 45, 사회 39개 등 총 153개 개념을 사용할 수 있다.
- 국어의 중1~3 학년군 개념도 사용 가능하다.
- 단어 뜻과 교과개념의 직접성·정확성을 먼저 지킨다.
- 여러 개념의 적합도가 비슷하면 현재까지 적게 사용한 개념을 먼저 검토한다.
- 개념 사용량은 가능한 한 고르게 하되, 균등 할당을 위해 부자연스러운 연결을 만들지 않는다.
- 자연스러운 교과 연결이 없으면 DAY/PART 주제, 그마저 어렵다면 단어 자체 장면으로 fallback한다.

## 예문

- 초등 6학년이 읽을 수 있는 쉬운 영어를 유지하되 중1 교과 맥락을 사용한다.
- 예문은 8~12단어이며 표제어 철자를 그대로 포함한다.
- 단어 뜻과 교과개념이 비유·은유가 아니라 직접 확인되어야 한다.
- 교과개념은 장식적 배경이 아니라 정확한 사실·관찰·행동으로 드러나야 한다.
- 나머지 자연스러움·시각화·안전 규칙은 기존 `req.txt` 기준을 유지한다.
- 이번 단계에서는 이미지 프롬프트를 만들지 않는다.

## 후보와 선택

- 작성자 ID는 `codex`, `antigravity`, `claude`다.
- 각 작성자는 새 세션에서 같은 공통 개념 배정표로 1,200개 예문을 독립 생성한다.
- 후보는 작성자별 전용 폴더에 저장한다.
- 선택은 세트가 아니라 단어별로 한다.
- 기존 예문과 세 모델 후보를 함께 비교한다.
- 본 생성 전 대표 샘플을 먼저 고르고, 선택 결과를 나머지 추천의 성향 기준으로 사용한다.
