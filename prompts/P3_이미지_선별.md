# P3 — 이미지 선별 (AI별 후보 → 최종)

2단계에서 AI별로 만든 이미지가 `content/image-candidates/<author>/<세트>/` 에 **이미 규격
정규화된 상태로** 쌓여 있다. 이 단계는 세트마다 어느 것을 쓸지 고르는 일이다.

```powershell
node remotion\scripts\status.mjs --day 01        # 이미지후보 열에 author별 장수가 보인다
```

## 1. 비교용 대지 만들기

```powershell
node remotion\scripts\make-image-sheets.mjs --day 01
```

세트 × author 마다 대지 한 장이 `remotion/out/qa-images/DAY01_01-10_set1__flow.png` 처럼
나온다. 20칸 격자에 파일명 라벨이 붙고, 없는 자산은 빈 칸으로 표시된다.
**author 별로 한 장씩 나란히 열어 비교한다.**

## 2. 무엇을 보고 고르나

우선순위대로 본다. 위에서 걸리면 아래는 볼 필요 없다.

1. **글자·로고 혼입** — 이미지 안에 읽을 수 있는 문자가 있으면 탈락
2. **의미 불일치** — 단어 이미지가 그 단어를 못 보여주거나, 예문 이미지가 예문 장면이 아님
3. **잘림** — 피사체의 핵심(얼굴·손·동작)이 프레임 밖으로 나감
4. **하단 1/4 침범** — 예문 이미지에서 중요한 요소가 아래 1/4에 걸침 (자막 바가 덮는다)
5. **화풍 일관성** — 한 세트 20장의 그림체가 비슷한가
6. 안전성 — 무섭거나 부적절한 묘사 (`req.txt` 기준)

세트 안에서 화풍이 갈리는 게 가장 눈에 띈다. **세트 단위로 한 author 를 고르는 것이
기본**이고, 몇 장만 다른 author 것으로 바꾸는 건 예외로 쓴다.

## 3. 올리기

세트 단위 (권장):

```powershell
node remotion\scripts\pick-images.mjs --author flow --set DAY01_01-10_set1 --dry-run
node remotion\scripts\pick-images.mjs --author flow --set DAY01_01-10_set1
node remotion\scripts\pick-images.mjs --author flow --set DAY01_11-20_set2 --set DAY01_21-30_set3
```

자산 단위로 섞을 때는 목록 파일을 쓴다:

```text
# picks.txt — "<세트>/<파일명> <author>"
DAY01_01-10_set1/03_flavor_word.png codex
DAY01_01-10_set1/07_edible_sent.png nano
```
```powershell
node remotion\scripts\pick-images.mjs --from-list picks.txt
```

- 최종 위치에 이미 있는 파일은 건너뛴다. 교체하려면 `--replace`
- 후보가 없는 자산은 `MISS` 로 보고된다 → 다른 author 후보로 채우거나 2단계에서 재생성
- **1회 상한 20세트(DAY 5개).** 눈으로 판정하는 단계라 그 이상은 스크립트가 거부한다

## 4. 세트가 다 찼는지 확인

```powershell
node remotion\scripts\make-image-sheets.mjs --day 01 --final
node remotion\scripts\status.mjs --day 01
```

`이미지 O` 가 되면 그 세트는 끝이다. 120세트 전부 `O` 가 되면 4단계로 넘어간다.

## 재생성이 필요할 때

불합격 사유별로 보강 문구를 붙여 그 자산만 다시 만든다 (`prompts/P2_이미지_생성.md`).

| 사유 | `--escalate` |
|---|---|
| 글자·로고 | `text` |
| 잘림 | `crop` |
| 단색 밴드·빈 화면 | `band` |
| 얼굴 부담 | `people` |

3회 시도해도 안 되면 `image_prompts.md` 의 장면 묘사 자체를 바꾼다
(`validate-content.mjs` 재통과 필수). 그래도 안 되면 `handover.md` 에 적고 넘어간다.
