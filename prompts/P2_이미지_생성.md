# P2 — 이미지 수급 (2,400장, 도구 자유)

1단계가 끝나면 `remotion/public/days/*/image_prompts.md` 에 프롬프트 2,400개가 있다.
이 단계의 목표는 **그 파일명들을 채우는 것**뿐이다. 어떤 도구로 만들든 상관없다.

## 규칙은 두 개다

1. `image_prompts.md` 의 프롬프트를 **그대로** 쓴다 (임의로 늘리지 않는다)
2. 결과 파일을 **목표 파일명 그대로** `inbox/` 에 둔다

파일명만 맞으면 나머지는 임포터가 처리한다. 확장자(jpg·webp·png), 크기, 비율,
`(1)` 같은 꼬리표, `DAY18_set1__` 같은 접두사는 신경 쓰지 않아도 된다.

```text
inbox/01_stomach_word.jpg          → DAY01_01-10_set1/images/01_stomach_word.png (1024×1024)
inbox/01_stomach_sent (2).webp     → DAY01_01-10_set1/images/01_stomach_sent.png (1600×900)
```

## 임포터가 흡수하는 것 (프롬프트로 싸우지 않는다)

```powershell
node remotion\scripts\import-images.mjs --author flow --dry-run   # 어디로 갈지 먼저 확인
node remotion\scripts\import-images.mjs --author flow             # AI별 후보로 반입
node remotion\scripts\import-images.mjs --author flow --replace   # 재생성분으로 교체

`--author` 를 주면 `content/image-candidates/<이름>/` 에 쌓인다 (3단계에서 고른다).
생략하면 최종 위치로 바로 들어간다 (도구를 하나만 쓸 때).
```

| 문제 | 임포터 처리 |
|---|---|
| 요청한 비율을 단색 밴드로 채움 | 테두리 단색 영역을 잘라낸다 (과하게 잘리면 되돌림) |
| 1:1 로만 나옴 / 비율이 다름 | 목표 규격으로 cover 크롭 — 단어는 주목영역, 예문은 위쪽 우선 |
| JPEG·WebP 로 나옴 | PNG 로 변환 |
| 해상도가 작음 | 목표 크기로 확대하고 경고 |
| 파일명이 지저분함 | 접두사·`(1)`·확장자를 무시하고 매칭 |

경고로 나오는 것들 — **경고는 자동으로 고쳐지지 않는다. 사람이 본다.**

- `크롭 34% (비율 불일치)` : 원본 비율이 너무 달라 많이 잘렸다. 잘린 그림을 확인한다
- `단색 62% — 밴드/빈 화면 의심` : 실패작일 가능성이 높다. 원본을 열어 본다
- `업스케일 768px → 1024px` : 선명도가 떨어질 수 있다

## 재생성 정책 (이게 v2 의 방식이다)

**미리 방어하지 말고, 실패한 자산만 고친다.**

1. 반입 후 contact sheet 로 세트 전체를 훑는다
   ```powershell
   node remotion\scripts\make-contact-sheets.mjs
   ```
2. 불합격만 골라 파일을 지우고, 증상에 맞는 보강 문구를 붙여 재생성한다
   ```powershell
   node remotion\scripts\generate-images-agy.mjs --set DAY01_01-10_set1 --escalate text
   ```
   | 증상 | `--escalate` 키 |
   |---|---|
   | 글자·로고 섞임 | `text` |
   | 피사체 잘림 | `crop` |
   | 단색 밴드·빈 화면 | `band` |
   | 사람 얼굴이 부담스러움 | `people` |
3. 3회 시도해도 안 되면 그 자산의 **장면 묘사 자체를 바꾼다** (`image_prompts.md` 수정 →
   `validate-content.mjs` 재통과). 그래도 안 되면 handover.md 에 적고 넘어간다.

보강 문구를 전량에 미리 붙이지 않는다. v1 에서 그렇게 하다가 프롬프트가 80단어로
불어났고, 약한 모델일수록 더 나빠졌다.

## 백엔드별 메모

**Codex (MCP `codex` 도구)** — `.mcp.json` 에 등록돼 있다. 파일 저장을 시키지 말고
`sandbox: "read-only"` 로 생성만 시킨 뒤 **절대 경로만** 받아서 `inbox/` 로 복사한다.
이 PC 의 Codex 샌드박스는 셸을 못 띄운다(`CreateProcessAsUserW failed: 5`).
순차 실행만 되며 1장당 60~90초다.

**agy (안티그래비티 CLI)** — 병렬이 되고 3장 동시 26초. 목표 파일명으로 `inbox/` 에
자동 스테이징까지 한다.
```powershell
node remotion\scripts\generate-images-agy.mjs --concurrency 4
node remotion\scripts\generate-images-agy.mjs --set DAY01_01-10_set1 --limit 4   # 시험
node remotion\scripts\generate-images-agy.mjs --list-missing                     # 누락 목록만
```
쿼터 소진(429)으로 끊기면 같은 명령을 다시 돌린다. 이미 있는 파일은 건너뛴다.

**Google Flow · nano banana · 기타 웹 UI** — 프롬프트를 붙여넣고 받은 파일을
목표 파일명으로 저장해 `inbox/` 에 넣는다. 여러 장을 한 번에 받아도 되고,
`--list-missing` 출력으로 남은 목록을 뽑아 쓰면 편하다. **비율 옵션은 아무거나 둬도 된다.**

한 세트 20장의 화풍은 되도록 한 도구로 맞춘다 (세트 안에서 그림체가 갈리면 눈에 띈다).

## 완료 조건

```powershell
node remotion\scripts\status.mjs
```

AI별 후보는 `이미지후보` 열에서 확인한다. 후보가 쌓이면 `prompts/P3_이미지_선별.md` 로 고른다.

**1회 실행 상한은 80장(DAY 1개)이다.** `generate-images-agy.mjs` 가 그 이상을 거부한다
(`--max` 로 최대 200까지 올릴 수 있지만 쿼터에서 끊기면 복구가 더 비싸다).
