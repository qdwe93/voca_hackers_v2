# samples — 규격 참고용 예시 (각 1개)

산출물 전체를 git 에 올리지 않는 대신, 규격과 화풍을 확인할 수 있는 예시만 남긴다.

| 파일 | 무엇 | 규격 |
|---|---|---|
| `example_word_1024x1024.png` | 단어 이미지 | PNG 1024×1024 |
| `example_sentence_1600x900.png` | 예문 이미지 | PNG 1600×900, 하단 1/4 는 자막이 깔린다 |
| `example_voice_zephyr.mp3` | Base 보이스 클로닝 낭독 (Zephyr) | 화자 4명 중 1번 |

이 예시는 v1 에서 만든 것이라 프롬프트가 길던 시절의 결과물이다. **v2 의 프롬프트 규칙은
훨씬 짧다** (`PLAN.md` 의 "이미지 프롬프트 규칙" 참조). 참고할 것은 문장이 아니라
**규격과 톤**이다.

새 이미지는 어떤 크기·비율로 받아도 된다. `import-images.mjs` 가 단색 테두리를 잘라내고
위 규격으로 맞춘다. 영상 예시는 올리지 않는다 (세트당 약 55MB).
